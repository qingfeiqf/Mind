# Mind MVP 范围定义

## 一、MVP 战略定位

### 核心原则
> "先做让人爱不释手的工具，再构建让想法流动的网络。"

MVP 聚焦于 **MindSpace** —— 一个 AI 驱动的去中心化无限画布创想工具。这是整个 Mind 生态的入口和基石。

### 为什么是 MindSpace?

| 维度 | MindSpace 优先 | MindWorld 优先 |
|------|---------------|----------------|
| 网络效应依赖 | 低（单人即可使用） | 高（需要用户基数） |
| 独立价值 | 高（工具本身有用） | 低（空广场无价值） |
| 技术复杂度 | 可控 | 高（需要推荐算法等） |
| 冷启动难度 | 低 | 高 |
| 数据积累 | 先有内容 | 先有用户 |

## 二、MVP 功能范围

### 2.1 功能分级

#### P0 - Must Have (MVP 必须)

**画布核心**
- [ ] 无限画布：平移、缩放、手势操作
- [ ] 节点创建：双击创建、拖拽移动、调整大小
- [ ] 连接线：节点间连线、可带箭头和标签
- [ ] 导航工具：迷你地图、一键回到中心、书签

**内容类型**
- [ ] 文本节点：Markdown 语法、基础样式
- [ ] 图片节点：拖拽上传、粘贴
- [ ] 链接节点：自动抓取标题和缩略图

**AI 认知伙伴**
- [ ] @AI 对话：追问、延展、举例、反驳
- [ ] @AI 人格切换：苏格拉底、乔布斯、费曼等预设
- [ ] 一键结构化：框选节点 → 思维导图/流程图
- [ ] 内容总结：框选区域生成摘要

**组织与结构**
- [ ] 节点成组：群组折叠、命名、整体移动
- [ ] 搜索功能：全文搜索、结果高亮
- [ ] 本地存储：所有数据自动保存到本地

**身份与确权**
- [ ] 钱包创建/导入：内置轻量钱包
- [ ] 想法确权：一键将想法哈希上链（测试网）
- [ ] 基础加密：本地数据加密存储

#### P1 - Should Have (MVP 增强)

- [ ] 历史版本：画布快照、版本回滚
- [ ] 代码块节点：语法高亮
- [ ] 涂鸦节点：基础画板
- [ ] 键盘快捷键：全面的快捷键支持
- [ ] 深色/浅色主题切换
- [ ] 多语言支持（中/英）

#### P2 - Nice to Have (后续版本)

- [ ] P2P 同步：多设备数据同步
- [ ] 发布到 MindWorld：将想法发布到社交广场
- [ ] 协作编辑：多人实时协作
- [ ] 代币经济：SPARK 积分系统
- [ ] 声音节点：语音记录想法

#### P3 - Future (远期规划)

- [ ] MindWorld 社交广场
- [ ] MindHands 协作平台
- [ ] DreamMore 众筹
- [ ] B-T/C 书茶咖
- [ ] 去中心化 AI

## 三、技术架构概览

### 3.1 MVP 架构 (简化版)

```
┌─────────────────────────────────────────────────┐
│                  MindSpace Desktop               │
│                  (Tauri 2.x)                     │
├─────────────────────────────────────────────────┤
│  React/TS UI Layer                              │
│  ├── Canvas Engine (PixiJS 8)                   │
│  ├── Editor (TipTap/ProseMirror)                │
│  ├── AI Chat Panel                              │
│  └── Sidebar (Node List, Search, Settings)      │
├─────────────────────────────────────────────────┤
│  Rust Backend (Tauri Commands)                  │
│  ├── Local Database (SQLite + rusqlite)         │
│  ├── File Storage (本地文件系统)                 │
│  ├── Wallet Module (ethers-rs)                  │
│  └── AI Proxy (HTTP → Claude API)               │
├─────────────────────────────────────────────────┤
│  External Services                              │
│  ├── Claude API (AI 推理)                       │
│  ├── IPFS Gateway (内容发布)                    │
│  └── Arbitrum Testnet (确权上链)                │
└─────────────────────────────────────────────────┘
```

### 3.2 MVP vs 完整版对比

| 组件 | MVP | 完整版 |
|------|-----|--------|
| 数据存储 | SQLite 本地 | SQLite + OrbitDB + IPFS |
| 数据同步 | 无（单设备） | Libp2p/Iroh + CRDT |
| AI 服务 | Claude API (中心化) | Claude + 本地模型 + Bittensor |
| 区块链 | 测试网确权 | 主网 + 完整代币经济 |
| 网络层 | 无 P2P | Libp2p 完整节点 |
| 协作 | 无 | Yrs CRDT 实时协作 |
| 身份 | 本地钱包 | DID + 链上身份 |

## 四、技术选型决策

### 4.1 前端技术栈

| 技术 | 选择 | 理由 |
|------|------|------|
| 框架 | React 19 + TypeScript | 生态成熟、组件库丰富 |
| 画布引擎 | PixiJS 8.x | WebGL 渲染、大量对象高性能、社区活跃 |
| 富文本编辑器 | TipTap (ProseMirror) | 可扩展性强、Markdown 支持好 |
| 状态管理 | Zustand | 轻量、TypeScript 友好 |
| 样式 | Tailwind CSS 4 + CSS Modules | 快速开发 + 局部样式隔离 |
| 构建工具 | Vite 6 | 快速 HMR、原生 ESM |

### 4.2 后端技术栈 (Rust)

| 技术 | 选择 | 理由 |
|------|------|------|
| 桌面框架 | Tauri 2.x | 安全、高性能、小体积 |
| 数据库 | SQLite (rusqlite) | 嵌入式、零配置、可靠 |
| 加密库 | ring / ed25519-dalek | 安全、高性能 |
| HTTP 客户端 | reqwest | 异步、可靠 |
| 序列化 | serde + serde_json | Rust 生态标准 |
| 异步运行时 | tokio | Rust 异步标准 |

### 4.3 智能合约

| 技术 | 选择 | 理由 |
|------|------|------|
| 语言 | Solidity 0.8.x | EVM 生态标准 |
| 框架 | Hardhat + TypeScript | 开发体验好、测试方便 |
| 安全库 | OpenZeppelin 5.x | 经过审计的标准实现 |
| 测试网 | Arbitrum Sepolia | 低 Gas、快速确认 |
| 钱包连接 | ethers.js v6 / viem | 现代、TypeScript 原生 |

### 4.4 AI 集成

| 技术 | 选择 | 理由 |
|------|------|------|
| 主力模型 | Claude 3.5 Sonnet | 推理能力强、成本合理 |
| 流式响应 | SSE (Server-Sent Events) | 实时逐字显示 |
| Prompt 管理 | 自建模板系统 | 灵活控制人格切换 |
| 本地模型 | Ollama + Qwen 2.5 7B | 离线可用、隐私保护 |

## 五、MVP 开发计划

### 5.1 Sprint 规划

| Sprint | 周期 | 目标 | 交付物 |
|--------|------|------|--------|
| **Sprint 0** | 第 1-4 周 | 技术 POC 验证 | 4 个 POC Demo |
| **Sprint 1** | 第 5-8 周 | 画布核心 + 基础编辑 | 可交互的画布 |
| **Sprint 2** | 第 9-12 周 | AI 集成 + 内容类型 | AI 伙伴可用 |
| **Sprint 3** | 第 13-16 周 | 身份 + 确权 + 打磨 | Alpha 版本 |

### 5.2 里程碑验收标准

**M0: 原型验证 (Sprint 0)**
- [ ] 画布渲染 10,000+ 节点, FPS > 50
- [ ] 节点创建、拖拽、连线流畅
- [ ] SQLite 数据持久化正常
- [ ] AI 对话流式响应正常

**M1: MVP Alpha (Sprint 1-3)**
- [ ] 完整的画布操作（创建、编辑、删除、连线、成组）
- [ ] 文本、图片、链接三种节点类型
- [ ] AI 对话 + 人格切换 + 一键结构化
- [ ] 本地数据自动保存和加载
- [ ] 钱包创建和想法确权
- [ ] 基础 UI 打磨（深色主题）

## 六、质量标准

### 6.1 性能指标

| 指标 | 目标 |
|------|------|
| 画布渲染 (10K 节点) | FPS > 50 |
| 节点创建响应 | < 16ms |
| 数据保存 | < 100ms |
| AI 首字响应 | < 2s |
| 应用启动时间 | < 3s |
| 内存占用 | < 500MB |
| 安装包大小 | < 50MB |

### 6.2 测试策略

- **单元测试**: 覆盖率 > 80%（工具函数、数据模型、AI 模板）
- **组件测试**: React Testing Library（UI 组件交互）
- **集成测试**: Tauri 命令测试（前后端通信）
- **E2E 测试**: Playwright（关键用户流程）
- **性能测试**: 画布压力测试、内存泄漏检测

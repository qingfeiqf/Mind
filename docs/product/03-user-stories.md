# MindSpace 用户故事地图

## 用户旅程总览

```
发现 → 安装 → 首次体验 → 日常创作 → AI 增强 → 组织管理 → 确权发布
```

---

## Epic 1: 首次体验 (Onboarding)

### Story 1.1: 安装与启动
> 作为一个创想者，我想快速安装并启动 MindSpace，以便立即开始记录想法。

**验收标准:**
- macOS/Windows/Linux 一键安装
- 首次启动 < 3 秒
- 显示简洁的欢迎引导

**任务拆分:**
- [ ] Tauri 打包配置（三平台）
- [ ] 欢迎页面 UI
- [ ] 首次启动数据目录初始化

### Story 1.2: 创建身份
> 作为一个新用户，我想快速创建一个身份，以便开始使用 MindSpace。

**验收标准:**
- 一键生成钱包（助记词备份引导）
- 或导入已有钱包
- 不强制要求理解区块链概念

**任务拆分:**
- [ ] 钱包生成模块 (Rust)
- [ ] 助记词显示与备份引导 UI
- [ ] 钱包导入功能
- [ ] 本地密钥加密存储

### Story 1.3: 第一个想法
> 作为一个新用户，我想在 30 秒内创建我的第一个想法节点。

**验收标准:**
- 打开应用即看到空画布 + 引导提示
- 双击任意位置创建文本节点
- 输入文字，节点自动调整大小

**任务拆分:**
- [ ] 空画布引导 UI
- [ ] 双击创建节点交互
- [ ] 文本节点输入与自动调整

---

## Epic 2: 画布核心体验

### Story 2.1: 画布导航
> 作为用户，我想自由地在画布上移动和缩放，以便浏览我的想法。

**验收标准:**
- 鼠标滚轮缩放 (0.1x - 10x)
- 鼠标拖拽平移
- 触摸板手势支持（捏合缩放、双指拖动）
- 迷你地图显示当前位置

**任务拆分:**
- [ ] PixiJS 画布初始化与视口控制
- [ ] 缩放/平移交互实现
- [ ] 迷你地图组件
- [ ] 一键回到中心按钮

### Story 2.2: 节点操作
> 作为用户，我想创建、移动、调整和删除节点，以便组织我的想法。

**验收标准:**
- 双击创建节点
- 拖拽移动节点
- 拖拽边缘调整大小
- Delete/Backspace 删除节点
- 多选（Shift+点击 或 框选）

**任务拆分:**
- [ ] 节点渲染组件
- [ ] 拖拽移动交互
- [ ] 调整大小交互
- [ ] 删除功能
- [ ] 多选机制

### Story 2.3: 节点连接
> 作为用户，我想在节点之间画连接线，以便表达想法之间的关系。

**验收标准:**
- 从节点边缘拖出连接线
- 连接线可带标签
- 连接线自动避让节点
- 支持箭头方向

**任务拆分:**
- [ ] 连接线渲染
- [ ] 拖拽创建连接交互
- [ ] 连接线标签编辑
- [ ] 路径计算算法

### Story 2.4: 节点成组
> 作为用户，我想将相关的节点分组，以便更好地组织复杂的想法结构。

**验收标准:**
- 框选多个节点后可创建群组
- 群组可折叠/展开
- 群组可命名
- 群组可整体移动

**任务拆分:**
- [ ] 群组数据模型
- [ ] 群组渲染（背景框）
- [ ] 折叠/展开动画
- [ ] 群组命名编辑

## Epic 3: 内容类型

### Story 3.1: 富文本编辑
> 作为用户，我想在节点中输入格式化的文字，以便清晰表达我的想法。

**验收标准:**
- 支持 Markdown 语法
- 标题、粗体、斜体、列表、代码
- 实时 Markdown 预览
- 节点内可滚动

**任务拆分:**
- [ ] TipTap 编辑器集成
- [ ] Markdown 扩展配置
- [ ] 节点内编辑器 UI 适配
- [ ] 自动保存机制

### Story 3.2: 图片节点
> 作为用户，我想在画布上放置图片，以便用视觉方式表达想法。

**验收标准:**
- 拖拽图片文件到画布创建节点
- 粘贴剪贴板图片
- 图片自动缩放到合理大小
- 图片本地存储

**任务拆分:**
- [ ] 图片上传/粘贴处理
- [ ] 图片节点渲染
- [ ] 本地文件存储管理
- [ ] 图片缩放交互

### Story 3.3: 链接预览节点
> 作为用户，我想粘贴一个 URL 自动生成卡片，以便快速引用外部资源。

**验收标准:**
- 粘贴 URL 自动抓取元数据
- 显示标题、描述、缩略图
- 卡片式布局
- 点击可打开链接

**任务拆分:**
- [ ] URL 元数据抓取（Rust 后端）
- [ ] 链接卡片 UI 组件
- [ ] 缓存机制
- [ ] 点击打开外部链接

## Epic 4: AI 认知伙伴

### Story 4.1: AI 对话
> 作为用户，我想在任意节点旁与 AI 对话，以便深化和完善我的想法。

**验收标准:**
- 输入 @AI 或点击 AI 图标唤起对话
- AI 回复以气泡形式出现在节点旁
- 支持流式逐字显示
- 保持上下文（知道当前节点和相邻节点内容）

**任务拆分:**
- [ ] AI 唤起交互（@ 触发 + 按钮）
- [ ] 对话气泡 UI 组件
- [ ] 流式响应渲染
- [ ] 上下文收集与 Prompt 构建
- [ ] Tauri 命令：AI 推理代理

### Story 4.2: AI 人格切换
> 作为用户，我想切换不同的 AI 人格，以便从不同角度审视我的想法。

**验收标准:**
- 输入 @苏格拉底 切换为苏格拉底式诘问
- 输入 @乔布斯 切换为产品思维视角
- 输入 @费曼 切换为通俗解释视角
- 支持自定义人格

**任务拆分:**
- [ ] 人格系统 Prompt 模板
- [ ] 人格切换 UI（@ 命令列表）
- [ ] 自定义人格编辑器
- [ ] 人格图标/视觉设计

### Story 4.3: 一键结构化
> 作为用户，我想框选散乱的节点后一键转换为思维导图，以便整理混乱的想法。

**验收标准:**
- 框选多个节点
- 右键菜单选择"一键生成思维导图"
- AI 分析节点关系，自动排列
- 连接线自动生成
- 动画过渡效果

**任务拆分:**
- [ ] 框选交互与右键菜单
- [ ] AI 结构分析 Prompt
- [ ] 自动布局算法（树形/力导向）
- [ ] 过渡动画
- [ ] 支持多种结构（思维导图、流程图、鱼骨图）

### Story 4.4: 内容总结
> 作为用户，我想让 AI 总结一片区域的内容，以便快速了解想法群的核心要点。

**验收标准:**
- 框选一片区域
- 右键选择"AI 总结"
- 生成结构化摘要
- 摘要可保存为新节点

## Epic 5: 搜索与导航

### Story 5.1: 全局搜索
> 作为用户，我想搜索画布上的所有内容，以便快速找到特定想法。

**验收标准:**
- Cmd/Ctrl+K 打开搜索
- 实时搜索结果
- 点击结果定位到画布位置
- 搜索结果高亮

**任务拆分:**
- [ ] 全文搜索索引（SQLite FTS5）
- [ ] 搜索面板 UI
- [ ] 结果定位与高亮
- [ ] 搜索历史

### Story 5.2: 书签系统
> 作为用户，我想为重要的画布位置添加书签，以便快速跳转。

**验收标准:**
- 添加/删除书签
- 书签列表面板
- 点击书签跳转到对应位置和缩放级别

## Epic 6: 数据管理

### Story 6.1: 自动保存
> 作为用户，我想让所有操作自动保存，以便不丢失任何想法。

**验收标准:**
- 所有操作实时保存到本地 SQLite
- 应用崩溃后重启可恢复全部数据
- 保存操作不阻塞 UI

**任务拆分:**
- [ ] SQLite 数据模型设计
- [ ] 自动保存机制（防抖 500ms）
- [ ] 崩溃恢复测试
- [ ] 数据迁移机制

### Story 6.2: 多画布管理
> 作为用户，我想创建多个画布（MindSpace），以便为不同主题分别记录。

**验收标准:**
- 创建/删除/重命名画布
- 画布列表面板
- 画布间快速切换

### Story 6.3: 想法确权
> 作为用户，我想将我的想法哈希上链，以便证明我是最早记录者。

**验收标准:**
- 一键确权操作
- 显示确权状态和链上交易哈希
- 确权后显示标识
- 测试网免费操作
